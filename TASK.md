# Task

## Technical Part – 20%

The technical part of your project will be graded according to the submitted code and the video demonstration where one of your team members needs to explain the code (similar to Assignment submissions) with the instructions on how to install, compile, and run it. Upload the video to a google drive and provide a link to it.

In addition, your submission needs to have a readme file with instructions on what tools and libraries (with links) are required for your code. Your code also needs to be clearly organized and have comments.
